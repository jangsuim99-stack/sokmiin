1. 갈래 특징: 가사

① 형식 : 고려 말에 발생하고 조선 초기 ( 사대부 ) 계층에 의해 확고한 문학 양식으로 자리 잡아 조선시대를 관통하며 지속적으로 전해 내려온 문학의 한 갈래이다. ( 4 )음보이며, 한 음보를 이루는 음절의 수는 대체로 ( 3 ~ 4 )음절이고 행(行)에 제한을 두지 않는 ( 연속체 ) 율문(律文) 형식을 갖고 있다.

② 작가층 : 주요 작가층은 ( 사대부 ) 계층이며, 장르 자체가 지닌 폭넓은 개방성 덕분에 양반가(兩班家)의 부녀자, 승려, 중·서민(中·庶民) 등 기술(記述) 능력을 갖춘 모든 계층이 참여했다. 내용 또한 까다로운 제한 요건이 없어 다채롭게 전개되었다.

③ 내용 : 조선 전기는 강호의 생활을 노래한 작품(정극인의 '상춘곡')이 주를 이루었으나 이후 여행, 유배, 정치적 진퇴 등 사대부들의 경험과 소회를 서정적으로 읊은 작품(정철의 '관동별곡', '사미인곡', '속미인곡')도 다수 창작되었다. 후기에 와서는 교술성이 짙어지거나 서사성이 강해졌다.

④ 향유 방식: 가사의 대표적인 향유 방식은 음악적 곡조에 맞춰 소리 내어 부르는 ( 가창 ), 낮게 읊조리며 율격을 느끼는 ( 음영 ), 그리고 눈으로 읽고 의미를 깊이 음미하는 ( 완독 )의 세 가지로 분류된다. 조선 전기는 사대부 중심의 가창·음영이 주를 이뤘으나, 조선 후기로 가면서 내용이 장편화되고 산문적이 되며 ( 필사 )와 독서 중심의 완독 형태로 확장되었다.

2. 다음 글을 참고하여 이 작품의 창작 의도를 파악해 보자.

정철은 조선 명종ㆍ선조 때의 문신ㆍ시인(1536~1593)으로 자는 계함(季涵), 호는 송강(松江)이다. 가사 문학의 대가로 국문학사상 중요한 <관동별곡>, <사미인곡> 등의 가사 작품과 시조 작품을 남겼다. 저서에 ≪송강집≫과 ≪송강가사≫가 있다. 정철이 관직에 머무르던 조선 선조 때에는 동인과 서인의 당쟁이 극심했고, 그는 서인 세력의 주요 인물로서 늘 당쟁의 한가운데에 있었다. 그러한 정치적 환경 때문에 정철은 여러 차례 탄핵을 받았고, 그때마다 선조가 정철을 두둔하며 정계에 복귀시켰다. 정철은 선조 18년에 네 번째로 벼슬에서 물러나 낙향하였고, 이때 임금을 그리워하는 마음을 담아 「사미인곡」, 「속미인곡」 등을 지었다.

☞ 창작 의도: 관직에서 물러나 낙향한 상태에서 임금(선조)에 대한 변함없는 충성심과 그리움을 두 여인의 대화 형식을 빌려 고백하기 위해서 창작하였다.

☞ 임(선조 임금)을 향한 변함없는 충성과 애정 및 이별의 슬픔 - 연군지정(愛君之情)
4. 다음 시어의 의미를 파악해 보자.
ʻ임’ ʻ구롬’, ʻ안개’, ʻ람’, ʻ믈결’
선조 임금 임과 화자의 사이를 막는 간신(간신배) 또는 당쟁 세력

4. 핵심 정리

갈래 가사, 양반 가사, 서정 가사, ( 대화체 ) 가사
성격 서정적, 연모적, 충의적, 비판적[ ( 간신 ) 비판 ]
제재 임을 향한 ( 그리움 )과 이별의 ( 슬픔 )
주제 연군지정(戀君之情) - 임(선조 임금)을 향한 변함없는 충성과 애정
특징 1. 두 여인(갑녀, 을녀)의 ( 대화 ) 구조로 구성되어 사실감과 입체감을 부여함.
2. 우리말의 미감과 순우리말 시어 표현을 극대화함.
3. <사미인곡(思美人曲)>의 속편으로, 감정의 객관화와 정절 표현이 더욱 뛰어남.
